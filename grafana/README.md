# Grafana Monitoring Stack

## Overview

A monitoring and observability platform was deployed within the Proxmox homelab environment using Docker Compose.

The solution provides real-time visibility into infrastructure performance, system health, resource utilization, and automated alerting through Grafana Alert Rules.
