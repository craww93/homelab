# Docker

Docker learning environment and container deployments.

## Completed

- Installed Docker Desktop
- Configured WSL Integration
- Ran Hello World Container
- Created First Docker Compose Project
- Deployed Nginx Container
- Configured Port Mapping

## Commands Used

### Run Hello World

```bash
docker run hello-world
```

### Run Nginx

```bash
docker run -d -p 8080:80 nginx
```

### Start Docker Compose

```bash
docker compose up -d
```

### Stop Docker Compose

```bash
docker compose down
```
